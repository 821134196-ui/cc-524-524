# 导师制辅导平台（Mentorship Hub）

企业新员工导师申请与辅导管理系统。零外部依赖（Node.js ≥ 22.5，使用内置 `node:sqlite` / `node:http` / `node:test`）。

## 一条命令启动

```bash
npm start          # 打开 http://localhost:3000
```

首次启动自动建库（`data/mentor.db`）、写入演示数据（含**换导师案例**）、生成虚构附件（`attachments/`），并启动进程内提醒任务（每 60 秒扫描，启动时先扫一次）。

```bash
npm test           # 运行测试：容量竞争 / 回避 / 私密权限 / 计划结项 / 时间冲突
```

## 内置演示案例

1. **换导师（主线）**：陈晓 × 周岩 计划进行中，陈晓已申请换到林岚 → 以主管「郑凯」或「冯敏」登录 → 审核台 → 通过并转介（原目标自动承接到新计划）。主管「吴倩」（产品部）与「钱进」（技术部）因回避制度无法处理该单。
2. **提前完成结项**：李萌 × 孙洁 计划 → 审核台 → 结项审核（类型：提前完成）。
3. **长期未开始**：王浩 × 赵启 确认 20 天无辅导次 → 启动时提醒任务自动预警并发送模拟消息，计划页与工作台显示红色标记。
4. **容量竞争**：林岚容量 1。陈晓的换导师申请与赵欣的待确认申请都指向她——先通过一个，另一个即报「名额已满」。（赵欣与林岚分属市场部/产品部，按回避制度请用「冯敏」或「钱进」确认赵欣的申请。）
5. **导师离职**：管理员 → 系统管理 → 标记离职 → 进行中计划挂起、自动发起换导师、消息通知。

## 业务规则与流转

- **申请 → 配对**：员工选技能与可交流时段 → 主管确认（生成辅导计划，初始目标来自申请技能）。
- **容量**：导师每月可带人数为上限；确认/换导师在 `BEGIN IMMEDIATE` 事务内检查并占用名额，两个主管并发操作由 SQLite 串行化，**不会重复占用**。
- **跨部门回避**：主管与员工、原导师或新导师任一同部门时，确认/审核被拒绝并提示转交；管理员不受限。
- **时间冲突**：申请时段与导师可带时段无交集 → 申请标记「时段冲突」并通知员工；辅导次预约与既有安排重叠 → 拒绝。
- **换导师**：员工申请（或导师离职系统自动发起）→ 主管审核 → 旧配对结束、旧计划标记「已转移」，新计划承接目标并关联原计划。
- **长期未开始**：确认超 14 天无辅导次 → 提醒双方；超 21 天 → 升级通知全体主管（`MENTOR_UNSTARTED_DAYS` / `MENTOR_ESCALATE_DAYS` 可调）。
- **结项**：双方任一方申请（正常 / 提前完成）→ 主管审核 → 计划关闭、名额释放；驳回则恢复进行。
- **私人反馈**：仅当事双方与授权主管可见，每次查看写入访问记录；作者强制为登录人，**导师不能替员工提交**。

## 技术要点

- **SQLite**（WAL）：计划、配对、反馈、消息回执、访问记录全部落库；`BEGIN IMMEDIATE` 临界区保证容量不超占。
- **本地附件**：`attachments/` 目录存虚构附件，元数据在 `attachments` 表，下载按权限校验并留痕。
- **进程内提醒**：`src/reminders.js` 定时扫描，`reminder_flags` 去重。
- **模拟消息适配器**：`src/messaging.js` 发送即写 `messages` 回执表 + `data/outbox.log`，接口可替换为真实适配器。
- **界面**：办公白底、炭灰文字与顶栏、少量明快绿点缀；匹配页导师姓名旁直接展示擅长领域与剩余名额；计划页按目标时间线展开纪要；私人反馈区为炭灰独立面板，与公开目标明确区分。

## 目录结构

```
server.js            启动入口
src/db.js            SQLite 连接、schema、立即事务
src/services.js      领域规则与状态流转
src/web.js           路由 + 服务端渲染
src/reminders.js     进程内提醒任务
src/messaging.js     模拟消息适配器
src/seed.js          演示数据（含换导师案例）
public/              样式与客户端脚本
attachments/         虚构附件（本地存储）
data/                SQLite 数据库与 outbox 日志（运行时生成）
test/                容量竞争 / 回避 / 私密权限 / 结项 / 冲突测试
```
